# Hermes · визуальная идентичность

Обложка [`hermes-hero.svg`](hermes-hero.svg) создана специально для этого репозитория. Это локальный векторный файл: без внешних изображений, шрифтов, скриптов и сетевых запросов. Он отображается в корневом `README.md`.

## Система оформления

| Роль | Цвет |
| --- | --- |
| Глубокий фон | `#080F23` |
| Подложка | `#111B36` |
| Основной текст | `#F7FAFF` |
| Акцент / наблюдаемость | `#49E4DE` |
| Второй акцент / исследования | `#A08BFF` |
| Приглушённый текст | `#B6C4DC` |

Ширина исходной композиции - 1280 × 420. Используйте относительный путь `assets/branding/hermes-hero.svg`, не внешний CDN. При изменениях сохраняйте `viewBox`, `<title>`, `<desc>`, читаемость в светлой и тёмной теме GitHub и оригинальную символику (связанная шестиугольная сеть с буквой H).

**Важно:** изображение в README не настраивает автоматически GitHub Social Preview. Для отдельного изображения предпросмотра репозитория понадобится экспорт в поддерживаемый GitHub растровый формат и ручная установка через настройки репозитория.
