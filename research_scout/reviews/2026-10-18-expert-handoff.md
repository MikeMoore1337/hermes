# H-03 / Issue #4 — пакет передачи четырёх исследований научному рецензенту

Дата: **18 октября 2026**, после [реального Crossref-аудита](2026-10-18-live-crossref-four-dois.md) и [проверки методологических ограничений](2026-10-18-publisher-methodology-risks.md).

**Результат этапа:** подготовлен воспроизводимый **перечень непроверенных вопросов** по каждому PMID, с ссылкой на конкретный первоисточник и пометкой глубины источника. Это **не** экспертное заключение, не проверка всех данных и не основание для клинических или фитнес-рекомендаций.

## Новый offline handoff

```bash
python3 -m unittest -q tests.test_research_science_handoff
python3 -m research_scout.science_handoff
```

Модуль `research_scout.science_handoff` получает четыре уже закреплённых owner-curated обзора из `research_scout.report_view`, сверяет точные PMID/DOI и открытые научные статусы, формирует **JSON только в stdout** без запросов в интернет, платных API, доступа к файлам или публикации. `schema=hermes-science-expert-handoff-v1`.

В пакете **19 отдельных заданий**: четыре для whey, пять для IRONMAN, пять для plant-food, пять для CRET. По каждому зафиксированы идентификатор, вопрос, конкретный URL, **фактическая глубина проверки**, отсутствие отдельно перепроверенных `effect_size` / `confidence_interval`, статус `NOT_INDEPENDENTLY_REVIEWED`, `reviewer=null` и `editorial_approval=false`. Нет средства выставить одобрение из CLI; цель — подготовить задачи человеку, а не автоматизировать научную аттестацию.

У всех четырёх остаются `scientific_claims_verified=false`, `full_text_independently_reviewed=false`, `publisher_clearance_verified=false`, `external_publication_allowed=false`, общий итог `HOLD_FOR_INDEPENDENT_SCIENTIFIC_REVIEW`. Даже факт существования текста, Crossref DOI или поискового индекса не повышает статус. Любая попытка получить пакет с подменённым DOI, отсутствующей публикацией, `full_text_reviewed=true`, `expert_review!=NOT_RUN` или ложным одобрением приводит к ошибке.

## Порядок независимой рецензии

1. Рецензент получает файл оригинала (с версией, DOI, датой и правами на использование), приложения, протокол/регистрацию, таблицы, список первичных работ. Для CRET сравнивает **официальный ClinicalTrials.gov**, его историю изменений и публикацию; стороннее зеркало — только поисковая подсказка.
2. В каждом из 19 заданий документируются проверенные раздел/таблица/страница, дата и версия, популяция, первичные исходы, данные об изменениях, размеры эффектов и 95% CI либо честное `NOT_REPORTED/NOT_APPLICABLE`. При отсутствии эффекта нельзя придумывать нулевую величину; `p>0.05` не доказывает эквивалентность.
3. Применяется методика под дизайн: критическая проверка выборки и смешения для IRONMAN, поиск прямых испытаний whey, AMSTAR 2 и независимая RoB 2/ROBINS-I-оценка для plant-food, sequence/washout/carryover и preregistered endpoints/multiplicity для CRET. Регистрация сама по себе не удостоверяет соответствие опубликованного анализа протоколу.
4. Отдельно проверяются уведомления непосредственно у издателя (version history/updates/crossmark), в Europe PMC и Crossref. Не использовать отрицательный фильтр одного каталога как issuer-wide clearance.
5. Отдельное лицо с нужной компетенцией подписывает утверждение **каждого** практического тезиса, допустимое население/применение, степень неопределённости, ограничения и лицензию. Затем требуется независимое решение владельца о любом публикационном канале YFC/Telegram/Second Brain. Новый JSON-пакет не является такой подписью и **не принимает её автоматически**.

## Точный статус

**Завершено:** программная подготовка **19 проверяемых заданий** с контролируемым контекстом, прямыми ссылками и запретом ложной аттестации; два публичных издательских оригинала изучены в ограниченных разделах, PubMed аннотации и Crossref reverse-filter четырёх DOI проверены ранее.

**Остаётся:** фактическая экспертная работа с полным текстом, всеми таблицами и протоколами, официальным trial registry, независимой RoB/AMSTAR 2 при уместности, повторным извлечением статистики и отдельной научной приёмкой. **Issue #4 — OPEN/PARTIAL, публикация — NO GO.** Новых recurring GET, LLM, агентов, сервисов, UI и расходов нет.
