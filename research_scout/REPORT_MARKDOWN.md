# H-03 - русскоязычный офлайн-просмотр библиографического пакета

[Issue #4](https://github.com/MikeMoore1337/hermes/issues/4).

Для просмотра существующего защищённого файла (после ручного разрешения чтения владельцем) используйте:

```bash
sudo sh -c 'cat /var/lib/hermes-research-scout/latest-citations.json' | python3 -m research_scout.report_markdown --stdin
```

Команда **не создаёт** научное заключение: она показывает русскоязычную структуру поверх уже собранных метаданных, сохраняет `HOLD`, `MANUAL_REVIEW`, `UNKNOWN`, не выводит незаполненные результаты как доказательства. Сам модуль не обращается в сеть, не записывает файлы, не запускает LLM и не делает публикаций. Он требует явный `--stdin` и принимает не более 64 КиБ JSON. Сырые поля рендерятся как текст, не как исполняемая разметка.

Этот промежуточный способ требует терминального доступа к VPS и **не является владельческой выдачей в Control Center**. Интеграция в существующий авторизованный Control Center должна отдельно проверить границы root-only хранилища и уже действующие полномочия. Не снижать права на каталог или файл ради интерфейса.

Формат `latest-citations.json` не содержит полных текстов, достаточных научных доказательств и ручной экспертной подписи, поэтому секция «Проверенные научные материалы» для данного источника всегда пуста. Для финальной приёмки #4 необходимы отдельные сверенные обзоры с первоисточниками, проверка исправлений и утверждённый read-only канал владельца.
