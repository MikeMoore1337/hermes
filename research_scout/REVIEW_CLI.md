# H-03 - локальный просмотр метаданных NCBI без сети

Программа `python3 -m research_scout.review_cli --review-stdin` принимает
**один JSON-массив из стандартного ввода** - только уже полученные через
официальный NCBI ESummary записи. Она не загружает статьи, не читает
контактный адрес, не вызывает Cloudflare/LLM и не публикует материалы.

Ограничения: максимум 64 КиБ входа и 50 записей, отказ при повторяющихся
JSON-ключах и неопределённых числах, точный набор допустимых полей,
обязательное совпадение PMID и URL, ручная проверка при неоднозначных датах.
Каждый результат содержит `scientific_claims_verified=false`.

Без `--review-stdin` вход вообще не читается. Файловое чтение,
запись, планировщик, Telegram и отправка в Second Brain отсутствуют.
`NO_DATA` не означает, что источники были найдены. `MANUAL_REVIEW`
означает **только** пригодность метаданных к просмотру человеком.

Для реального источника необходимо отдельно настроить контакт NCBI
без записи в репозиторий и выполнить ограниченную проверку egress. Запуск
этого модуля не снимает ограничений по Scientific Claims YFC.
