# Europe PMC - научные исследования без регистрации NCBI

Сервис: [Europe PMC REST](https://europepmc.org/RestfulWebService), открытые научные метаданные, размещённые через EMBL-EBI. [H-03 Issue #4](https://github.com/MikeMoore1337/hermes/issues/4).

**Зачем Hermes:** Research Scout должен искать публикации по фиксированным темам (силовые тренировки, гипертрофия и восстановление), проверять фактические PMID/PMCID/DOI, дату и ограничения и готовить кандидатов для ручного научного обзора. Это **не** новый редакционный бот, не автоматическая медицинская рекомендация и не замена существующих 16 источников новостей YFC.

Ранее разработанный NCBI E-utilities pipeline зависит от регистрации `tool/email` и общего IP лимита. Владелец сообщил о HTTP 500 при попытке регистрации. Для **Europe PMC регистрация, API-ключ, платная подписка и ввод карты не требуются**. Сервис позволяет получать публичные данные в JSON. Другой справочный источник DOI - [Crossref Public REST](https://www.crossref.org/documentation/retrieve-metadata/rest-api/access-and-authentication/), тоже допускает анонимный бесплатный доступ; отдельная интеграция с ним пока не включена.

## Доказательства реального доступа на VPS (15.10.2026)

- Europe PMC `https://www.ebi.ac.uk/europepmc/webservices/rest/search`: HTTPS 200, JSON, поиск `TITLE_ABS:"resistance training" AND FIRST_PDATE:[2026-09-15 TO 2026-10-15]` дал `hitCount=68` и 2 ограниченные записи. Второй поиск по `muscle hypertrophy` дал `hitCount=9`. Доступен поисковый режим `resultType=lite`, 2 записи ~2.5 KiB.
- Crossref `https://api.crossref.org/works/10.1038%2Fs41586-020-2649-2`: HTTP 200, JSON с DOI, без токена.
- Это **сетевые проверки только публичных метаданных**, не проверка конкретного научного вывода.

## Безопасный запуск

```bash
python3 -m research_scout.europe_pmc --topic resistance-training
# {"status":"NOT_EXECUTED"} - по умолчанию ни одного запроса

python3 -m research_scout.europe_pmc --execute --topic resistance-training
```

Второй запуск делает **один** запрос к точному `www.ebi.ac.uk:443`, список тем фиксирован кодом. Только публичный DNS/IP, pin на адрес соединения, TLS проверка по настоящему hostname, не следовать redirects, проверка MIME/тела, максимальная длина ответа 32 KiB, 8 секунд, без повторов. Нет cookies/прокси/браузера/моделей/произвольных запросов. Результат печатает **только счётчики и статусы**, не сырые тексты/аннотации.

Внутренний `run()` возвращает строго ограниченные библиографические записи для ручной проверки: статус `MANUAL_REVIEW` или `HOLD`, DOI, фиксированный ссылочный URL, дата и идентификатор. Непроверенные даты, DOI и подозрительные инструкции блокируются, дубликаты DOI не считаются независимым подтверждением. Даже `MANUAL_REVIEW` **не** означает научную доказанность и не разрешает публикацию.

Новый клиент не включает расписание и не записывает в YFC/Second Brain/Telegram; для автоматических отчётов и канала доставки понадобится отдельный контракт научной проверки и согласованное расписание. Никаких NCBI токенов, биллинга или регистраций не нужно. Старые модули NCBI не удалены без проверки зависимостей; они остаются неактивными.


## Проверка DOI через Crossref (H-03)

Второй независимый источник регистрации DOI: [Crossref REST](https://api.crossref.org/works/10.1038%2Fs41586-020-2649-2), без личного кабинета, регистрации, карты или токена. Модуль `research_scout.crossref` делает **один** запрос только на точный `api.crossref.org:443`, фиксирует DNS/IP соединения и TLS по hostname, запрещает redirect, использует MIME/body limit 48 KiB, 9-секундный timeout, 0 повторов и 0 платных fallback.

```bash
python3 -m research_scout.crossref --doi 10.1038/s41586-020-2649-2
# NOT_EXECUTED
python3 -m research_scout.crossref --execute --doi 10.1038/s41586-020-2649-2
```

Успех `DOI_METADATA_MATCH` подтверждает **совпадение регистрационного идентификатора DOI** в Crossref, но НЕ доказывает качество, статистическую корректность, научную истинность, рецензирование статьи, независимость исследований или права на републикацию. Источник второго DOI не считается вторым независимым исследованием. Несовпадение, 404, таймаут, 429, странный JSON и неизвестный DOI -> UNKNOWN/HOLD, без автоматической публикации.

Связка `review_candidate()` принимает только уже проверенный Europe PMC кандидат `MANUAL_REVIEW`; если DOI отсутствует - HOLD без сетевого запроса. Отчёт не печатает исходный заголовок, аннотацию или любую строку API. Для выбора исследования и разбора эффектов нужен человек.
