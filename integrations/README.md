# Интеграции

Пока **нет активных интеграций**. Создавать адаптер только под конкретный одобренный Issue и подтверждённый API контракт. YFC - без обхода собственных проверок; Second Brain - только одобренный read-only API после #386; GitHub - минимальные права для соответствующего агента.

См. [ownership](../docs/architecture/OWNERSHIP.md).
