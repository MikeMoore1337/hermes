# H-09 - реестр интеграций Hermes

[Issue #61](https://github.com/MikeMoore1337/hermes/issues/61). Реестр **не** является каталогом разрешённых к запуску инструментов, не хранит токены, не делает HTTP-запросов, не устанавливает пакеты и не меняет настройки VPS. Данные хранятся в [candidates.json](candidates.json), проверка выполняется `python3 -m integrations.registry --validate` и в CI.

## Статусы и порядок принятия

- **GO** - известный уже проверенный сценарий, точный набор разрешений и доменов зафиксирован **дополнительно в исполняемом коде** `APPROVED_GO_CONTRACTS`. GO не предоставляет агенту capabilities и не включает runtime. Изменение статуса требует отдельного PR, отрицательных тестов и согласования фактического запуска.
- **DEFER** - информация о цене, правах, источнике, доступе, регистрации, владельце или реальном тесте не подтверждена. Не устанавливать и не выдавать сетевые разрешения. Например, приватный Hermes GitHub Actions ответил HTTP 404 при корректных правах на локальный токен, поэтому остаётся DEFER.
- **REJECT** - неприемлемые варианты: неконтролируемые расходы, общий пул чужих подписочных OAuth-токенов, выполнение недоверенного кода или обход запретов.

Каждая запись требует явного источника документации, версии/даты проверки, известного или честно неустановленного лицензирования, сценария пользы, режима оплаты/карты, доступа к данным, эффекта операции, точных доменов, ограниченных разрешений, ссылки на Issue и причин решения. **Наличие GO в JSON не активирует сервис**: требуется кодово закреплённый контракт, отдельная проверка безопасности и существующая политика owner approval.

## Уже проверенные интеграции и ограничения

- Локальная обработка фактов стандартной библиотекой Python - без сети и внешней стоимости.
- GitHub Actions YFC - только 3 публичных набора метаданных по строго фиксированному GET. Отдельная VPS-проверка успешна.
- Приватный Hermes GitHub Actions - ограниченный read-only доступ доказан 15.10.2026 на VPS; отдельный наблюдатель включён, 1 GET / 15 мин по main quality workflow; никаких действий записи, сырых логов и персональных данных.
- NCBI ESearch/ESummary - контакт разработчика сохранён, но регистрация инструмента, общий IP rate-limit, реальный разрешённый запуск и научная проверка остаются условиями допуска. Не дублировать YFC редакционную инфраструктуру.
- Telegram Ops Watch - отдельный бот и приватный chat ID, подтверждён настоящий `message_id=4` и SQLite ACK, отдельный таймер включён. Ограничено отправкой фиксированного оповещения владельцу; не распространять GO на чужие чаты, группы или публикации.
- Cloudflare Workers AI Free - публичная квота проверена по документации, но статус Free конкретного аккаунта не подтверждён (`ACCOUNT_FREE_UNVERIFIED`); текущий ручной пилот не делал live-запросов, поэтому для запуска остаётся DEFER. Без перехода на платные модели.
- Second Brain - blocked до #386 и отдельного разрешённого API. Прямой vault/Git/filesystem доступ запрещён.
- Неофициальные прокси подписок/OAuth pools - REJECT.

## Процедура и откат

1. Создать отдельный Issue с конкретным сценарием, оценить альтернативы без установки.
2. Проверить *официальную* документацию, лицензию и актуальную политику оплаты. До получения фактов поставить DEFER, а не угадывать.
3. Описать минимальные данные, одобренные домены и операции, разрешения токена, регистрацию, допустимый объём, ограничение запросов и негативные сценарии (неожиданная стоимость, 401/403/404/429, redirect, SSRF, prompt injection).
4. Ввести контракт для нового GO в коде, независимый review и CI. Отдельное разрешение владельца на реальный доступ, хранение секрета, запуск службы или доставку сообщений остаётся обязательным.
5. Для отката вернуть запись в DEFER/REJECT и удалить из `APPROVED_GO_CONTRACTS` через PR, отключить соответствующий **отдельный** runtime по инструкции конкретной интеграции. Не удалять чужие секреты/контуры, не запускать controller/recovery.

Новые интеграции не включаются «конвейером» только из-за статуса GO в этом реестре. Реестр защищает от ошибочного выбора, а не заменяет права ОС/сети и утверждение владельца.
