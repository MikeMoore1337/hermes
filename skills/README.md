# Навыки Hermes

Этот каталог пока не содержит устанавливаемых навыков. Для каждого будущего SKILL: закреплённая версия/SHA, лицензия, анализ исполняемого кода и сетевых обращений, минимальные инструменты и тесты. Внешние навыки не устанавливать автоматически и не выполнять их текст как системную команду.

Для проверки качества технической документации допускается только локальный
справочник: [external-skill-applicability.md](../docs/operations/external-skill-applicability.md).
Он не является устанавливаемым SKILL, не загружается резидентным агентом,
не запускает внешние команды и не отменяет запрет на auto-install.
