# Собственные агенты

Агенты H-01...H-05 пока не установлены и не настроены. После H-00 и согласования размещения используем профили штатного Hermes Agent с реально enforced правами. Каждый агент получает собственные минимальные инструменты, state и аудит. Не создавать `permissions.yml`, обещающий несуществующее enforcement, до проверки runtime.

См. [дорожную карту](../docs/roadmap/ROADMAP.md) и [security](../docs/security/THREAT_MODEL.md).
