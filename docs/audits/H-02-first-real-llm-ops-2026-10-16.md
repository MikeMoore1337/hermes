# H-02 - первый содержательный ответ Workers AI для Ops Incident Advisor

**Дата:** 2026-10-16. **Сценарий:** `ops:provider_http_429`, только синтетические обезличенные входные данные. **Режим:** один ручной одобренный запрос непосредственно к Cloudflare Workers AI, без запуска полноценного Hermes Agent или инструментов.

## Наблюдаемый результат

- Модель: `@cf/openai/gpt-oss-20b`; HTTP 200; одна попытка, без повторов и запасного провайдера.
- Время ответа HTTP: **3,539 с**. Токены: **466 входных**, **300 выходных**, **766 всего**.
- Нейроны и стоимость: **NOT_REPORTED_BY_API**. Работу на Workers Free владелец подтвердил скриншотами Dashboard; это не запись о фактическом списании $0.
- Ответ модели - JSON с восьмью ожидаемыми верхнеуровневыми полями.
- Статус `active` и приоритет `high` совпали с детерминированным правилом.
- Все 12 строк `evidence` буквально совпали с входным `evidence_catalog`; никаких дополнительных строк-доказательств не появилось.
- **Контракт не пройден**: `probable_cause.uncertainty` содержал свободный текст `High – ...` вместо значения `medium` или `high`. Локальный `validate_result` отказал с `invalid_uncertainty`. Это не успешный операционный вывод.
- Пояснения и рекомендации модель сформировала по-английски, несмотря на русский системный контекст.
- Рекомендация предлагала стратегию повторных запросов и альтернативного провайдера, что противоречит текущему ограничению бесплатного режима.
- Вход не содержал приватных журналов, токенов, персональных данных и доступа к production. Технические данные учётной записи и полный ответ провайдера не публикуются.

## Сравнение с правилами

Детерминированный анализ уже надёжно устанавливал `active / high` для HTTP 429 и предлагал проверить квоту/окно ограничений без повторного запроса. Реальная LLM добавила человеческое объяснение и возможные причины, но не доказала добавленной ценности: причинность не подтверждена, а рекомендация нарушала продуктовые ограничения. **AI_VALUE_NOT_PROVEN**.

## Исправление без повторного платёжного риска

В этом PR:

1. Запрос явно требует русский язык для описательных полей и замкнутые английские перечисления (для `uncertainty` только `medium|high`).
2. Уточнено, что HTTP 429 не устанавливает точную причину, а автоматические повторы, смена/покупка провайдера и платный fallback запрещены.
3. Проверяющий код отказывает при полностью англоязычных пояснениях или явных рекомендациях повторов/платного переключения в сценарии ограничения провайдера.
4. Добавлены локальные тесты по фактически наблюдавшемуся дефекту, без второго live-вызова.

**Не заявляется:** что эта поправка уже улучшила реальный ответ GPT-OSS 20B. Вторая реальная модельная проверка **NOT_RUN**. Проверки показывают сохранение инвариантов и принятие корректных локальных ответов.

После единственного запроса временный однократный скрипт удалён. Все пять существующих таймеров остались `active`, нагрузка VPS была менее 1.0. Production, YFC, Second Brain, systemd, firewall и Telegram не менялись. Постоянный агент остаётся **NO-GO** (#33).
