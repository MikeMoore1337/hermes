## Новая версия и supply chain

Локально скачан public wheel `pyjwt-2.15.1-py3-none-any.whl` официальным pip `--no-deps --only-binary=:all:`, SHA256 локального wheel **совпал с hash на официальной HTML-странице PyPI**:

`42d59d631f7768a1028a64c7ff581a9bf7519804daf91fc5b6c56e30eec5e193`.

Информация PyPI указывает Trusted Publishing и verified publish attestation для wheel, но **самостоятельная верификация Sigstore bundle не выполнялась**.

Рецепт `docker/v0222-pyjwt-fixed-candidate/Dockerfile` и безопасный helper `scripts/prepare_v0222_pyjwt_candidate.py` перепинены на **PyJWT 2.15.1** и full SHA256, исходный image exact digest остался неизменным. Дополнительные синтетические tests должны пройти в Linux CI. **Сборка 2.15.1 и его Trivy/crypto/native-tool повторные испытания ещё НЕ выполнены на момент этого акта** (подключённый Docker Desktop стал недоступен по Remote Commander), поэтому старый локальный image ID **не относится к 2.15.1**.
