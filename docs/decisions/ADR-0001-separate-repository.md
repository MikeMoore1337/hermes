# ADR-0001: Независимый репозиторий для Hermes

Дата: 2026-10-11  
Статус: принято владельцем

## Контекст

Hermes уже выполняет YFC-новости в специальном hardened контуре. Планируются самостоятельные Ops Watch, Research Scout, QA Advisor, знания Second Brain и ограниченные интеграции. Хранить их вместе с YFC означало бы смешивать release ownership, права и проектную документацию.

## Решение

Приватный `MikeMoore1337/hermes` для собственной конфигурации Hermes Agent, интеграций, навыков, тестов и инфраструктурных скриптов. Движок `NousResearch/hermes-agent` используется как upstream, **не** заменяется форком и не копируется сюда целиком.

## Последствия

+ Независимые Issues/CI/релизы, роли и полномочия.
+ Меньше пересечений с YFC/Second Brain.
- Требуется явное API-совместимое взаимодействие и организация отдельного релиза.
- Нельзя считать новостной конвейер мигрированным только на основании нового репозитория.

Любой реальный перенос news runtime требует отдельного плана, тестов, shadow/cutover, rollback и явного owner GO.
