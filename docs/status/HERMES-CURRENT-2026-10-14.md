## Ограничения и честные статусы

- Публикация исследования и тренировочных рекомендаций не автоматизирована. Метка MANUAL_REVIEW - только предложение проверить первоисточник.
- Без реального HERMES_NCBI_CONTACT_EMAIL нельзя делать запросы NCBI; адрес-заглушку не использовать.
- Попытка stage-only передачи новых модулей на VPS была отклонена проверкой безопасности, повторный обход не выполнялся.
- GitHub PR #39 остаётся открытым, не считать его включённым в main.
- Telegram Bot API message_id означает принятие сервером Telegram, но не прочтение владельцем.
- Прежние описания 'готово' без CI + наблюдения VPS не следует трактовать как production done.
