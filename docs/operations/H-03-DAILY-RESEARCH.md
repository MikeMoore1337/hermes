# H-03 - ежедневный публичный библиографический отчёт Research Scout

[Issue #4](https://github.com/MikeMoore1337/hermes/issues/4). Источники - **только Europe PMC и Crossref**, HTTPS метаданные, без NCBI-регистрации, API-ключей, карты, платного тарифа, языковой модели или импорта в YFC. Это **отдельный** модуль, не трогает существующие новости и редакционный бот.

## Что делает

- До трёх строго фиксированных запросов Europe PMC в сутки: силовые тренировки, гипертрофия мышц, восстановление; фиксированное окно последние 30 дней и максимум 2 записи по теме.
- Если найден DOI подходящего для ручной проверки кандидата, выполняет **не более одного** Crossref DOI lookup. Максимум 4 сетевых GET за проход, без retry, без redirect, с TLS/DNS private IP guard, каждый timeout 8-9 секунд, ответы 32/48 KiB.
- Делает минимальный локальный отчёт `/var/lib/hermes-research-scout/latest-citations.json` (каталог `0700 root`, файл `0600 root`). В отчёте: временная отметка, открытые библиографические ссылки, заголовки, DOI, статус, причины HOLD, отметка подтверждения *регистрации DOI*, но **не научной истины**.
- `MANUAL_REVIEW` означает «нужна проверка научного оригинала», `HOLD` означает недостаточные либо небезопасные сведения, `NO_DATA` означает отсутствие доступных кандидатов. Отсутствие DOI, ошибка одного источника или повтор статьи в разных темах не превращается в независимое доказательство.
- В журнал systemd выходят **только статусы, числа кандидатов и количество запросов**, ни сырые заголовки, ни токены, ни медицинские советы. Никаких сообщений третьим лицам, Telegram-публикаций, редакционных действий, вызовов модели, обновлений сайта, GitHub write.

## Безопасная эксплуатация

```bash
python3 -m research_scout.daily_digest
# NOT_EXECUTED

# Отдельно проверенный и разрешённый хост:
sudo bash /opt/hermes-agent-owner/deploy/install-research-scout.sh
systemctl status hermes-research-scout.timer --no-pager
journalctl -u hermes-research-scout.service --no-pager -n 20
```

Установщик не изменяет новостные timers, а лишь проверяет их активность. Служба sandbox systemd без Linux capabilities, без доступа к приватным каталогам YFC/Ops/QA/GitHub tokens, защищена по RAM/CPU и времени. По умолчанию один запуск при включении таймера через ~2 минуты для проверки, затем ежедневно около **19:30 по времени VPS (МСК)** с возможной задержкой до пяти минут; `Persistent=false`, никаких догоняющих повторов после простоя. Первоначальный явный GET до включения расписания обязателен.

Отключить только новый Research Scout (не новости и не Ops):

```bash
sudo systemctl disable --now hermes-research-scout.timer
```

Нельзя отключать **связанный через symlink** `hermes-discovery.timer` ради теста. При частичной недоступности источника `status=HOLD`, сервис сигнализирует неуспех, но файл содержит причину; ни одной научной публикации не происходит.

## Научная достоверность и оставшиеся блокировки

Включённая **сборка открытых метаданных не является полностью автономным научным экспертом**. Для каждого потенциального вывода нужны PMID/DOI, методы (РКИ/наблюдательное/обзор), population, эффект и ограничения, проверка полного оригинала, лицензия/права на текст, доверенное подтверждение без двойного подсчёта и ручное разрешение публикации. Ни одно из этого автоматический извлекатель не утверждает.

Для внешней выдачи отчётов пользователю требуется отдельный утверждённый канал. Прямых изменений YFC, Second Brain или ночного AI Agent не производится. Этот read-only ежедневный процесс можно эксплуатировать независимо от отключённого постоянного Hermes Agent.
