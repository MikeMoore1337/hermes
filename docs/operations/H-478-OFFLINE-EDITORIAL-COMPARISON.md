# Hermes #478 - offline сравнение двух публичных синтетических научно-популярных черновиков

## Проверка пробела и владения

- Hermes H-13 editorial_preflight/ru_check.py уже обнаруживает шаблонные фразы, абсолютные утверждения и юридические подсказки. Он не сверяет две версии текста и не подтверждает факты.
- Hermes H-13 editorial_review/public_draft.py уже проверяет явные [ref:S1]-маркеры, проценты без ссылок и некоторые опасные медицинские/правовые формулировки. Он не устанавливает истинность ссылок и не выбирает лучшую редакцию.
- content_research/agent_reach_preflight.py занимается доступностью каналов, а не редакционными утверждениями.
- YFC владеет публикацией, медицинской проверкой, реестром источников и редакционным решением (docs/architecture/OWNERSHIP.md, #7); Hermes не имеет права публиковать или изменять YFC.
- Выполнено source-pinned сравнение с Toolkit main@cf402c4f6c6cfe0408cf26a9d10d0cb63ed51ea7: Clear Voice 1.1.0 (.agents/skills/clear-voice/SKILL.md, profiles/research-digest.md, references/fidelity.md, evals/SCORECARD.md) - редакторские правила, не исполняемый проверяющий код и не научная экспертиза. Настоящий A/B на одной модели и независимая человеческая оценка не выполнялись; преимущество над Clear Voice не заявляется.

**Новый ограниченный пробел:** проверка регрессий в уже предложенной редакции без второго конвейера генерации материалов.

## Контракт v1

- Только явно маркированные PUBLIC_SYNTHETIC / scientific_draft объекты и две предоставленные версии. Никакого чтения файлов, сети, API или запуска моделей.
- editorial_review/compare_drafts.py: compare(payload), schema hermes-h478-editorial-pair-v1, выход hermes-h478-editorial-rubric-v1.
- Сверка ссылок [ref:S#], DOI, PMID, URL, числовых литералов и проверяемых лексических маркеров: отрицания, эпистемические оговорки/кванторы, группа исследования. Новые бездоказательные причинные и абсолютные утверждения блокируются. Перечни русских слов ограниченны, морфологическое покрытие неполное.
- Два измеримых стилистических признака: меньше перечисленных шаблонных фраз и меньше строго идентичных повторных предложений.
- **REFUSED:** нарушения якорей источников, чисел, ссылок, отрицаний или новые рискованные утверждения.
- **REVIEW_CANDIDATE:** зафиксировано уменьшение формул/повторов без перечисленных нарушений. Это только предложение человеку.
- **NO_CHANGE:** одинаковые тексты, либо изменение без измеримого улучшения, либо сокращение без доказательства сохранения смысла.
- Для любого статуса: publication_allowed=false, automatic_replacement=false, source_content_verified=false, scientific_facts_verified=false, citation_sentence_alignment_verified=false, author_voice_verified=false, independent_expert_blind_review=NOT_RUN.

**Важная граница:** одинаковое количество чисел/ссылок не доказывает сохранение их привязки к предложениям, смысла, контекста, причинности или авторского голоса. Указанные проверки нужны, чтобы отвергать явные регрессии, а не автоматически утверждать качество. Умолчание = ручная проверка.

## Синтетические RU проверки

tests/test_h478_editorial_comparison.py содержит двадцать случаев: неизменный текст, удаление формулы, удаление повтора, сокращение без доказанного улучшения, подмена процента, DOI и PMID, подмена ссылки и неизвестный источник, повреждённый маркер ссылки, изменение отрицания, новая причинность, абсолютное медицинское утверждение, неподдерживаемые границы входа, внедрение поля instructions и инертный текст с попыткой приказа; дополнительно удаление осторожной оговорки, замена некоторые→все, взрослых→мыши, изменённый URL и неизменная популяция/оговорка.

Все примеры вымышлены, DOI/PMID только строковые метки. Никакой внешней проверки соответствующих публикаций нет.

## Проверки и release gate

- Адресный запуск: python3 -m unittest tests.test_h478_editorial_comparison -v
- Общий CI репозитория на точном SHA PR и затем main.
- Никаких изменений существующего работающего редакционного потребителя, задач планировщика, Control Center, авторизации, BRC, YFC и Second Brain.
