# H-01 - безопасная проверка закреплённого v0.22.1 на отдельном Docker-хосте

> **Историческая проверка точного v0.22.1, не текущая рекомендация к запуску.**
> 15.10.2026 официально вышел v0.22.2; upstream подтвердил, что v0.22.1
> собран не из того commit. Новый read-only кандидат описан в
> [аудите v0.22.2](../audits/H-01-v0222-official-release-candidate-2026-10-16.md).
> Все прежние v0.22.1 тесты применимы только к прежнему digest;
> resident Agent остаётся NO-GO.

Сценарий: [Issue #33](https://github.com/MikeMoore1337/hermes/issues/33). Рабочий VPS Hermes не подходит для загрузки новых больших образов: ранее попытка вызвала load1 до 3.96 при защитном пороге 1.30. Для проверки выбран отдельный Windows Docker Desktop, где исходно было более 200 ГБ свободного места и не запускались рабочие процессы Hermes.

## Принцип

Проверяется **ровно один immutable AMD64 digest** `sha256:cd9cb455576d27c9b6311de1104494ad7e221b6e68dc77e9ac2a8af661a4dc21` из официального релиза v0.22.1, совпавшего с release receipt. Пробник ничего не скачивает: перед запуском локально должен существовать этот образ; отсутствие даёт отказ.

После явного `--execute` выполняются только две команды Docker: чтение `RepoDigests` и архитектуры, затем единичный одноразовый контейнер с запретами `--pull=never --platform linux/amd64 --network none --read-only --cap-drop ALL --security-opt no-new-privileges --user 65534:65534 --cpus 0.25 --memory 256m --pids-limit 25`. Никаких томов, сокетов, моделей, доступов к YFC, Telegram, данным владельца или секретам.

Внутри `/opt/hermes/.venv/bin/python` читает публичный embedded `/opt/hermes/install-stamp.json` и **только** имена/версии локальных пакетов через `dpkg-query -W` и `importlib.metadata`. На стороне вызывающего процесса данные проверяются, агрегируются в детерминированный SHA256, выявляются повторяющиеся имена. Журнал выводит только количество пакетов, коды состояния и хеш списка, без исходных сведений, секретов или сырых ответов команд.

Команда из корня репозитория: `python3 -m scripts.verify_v0221_local_image` (без сети / Docker). После локальной загрузки образа: `python3 -m scripts.verify_v0221_local_image --execute`.

**Статус `EMBEDDED_STAMP_MATCH_IMAGE_UNATTESTED` не доказывает source-to-image parity.** Значение коммита внутри файла могло быть записано на этапе сборки и не удостоверяет байты всех исходников. Это **не подписанная полная SBOM**, не сканер уязвимостей, не проверка лицензий и не нагрузочное испытание. `resident_agent_allowed=false` и код выхода 2 даже при совпадении. Полный допуск AI Agent всё ещё требует независимой цепочки исходник-сборка-образ, SBOM, безопасного нагрузочного теста и технического запрета платного биллинга.

Этот инструмент не изменяет `systemd`, таймеры Hermes или исходный образ YFC; его можно повторить на другом Docker-хосте после строгой проверки источника и ресурсов.
