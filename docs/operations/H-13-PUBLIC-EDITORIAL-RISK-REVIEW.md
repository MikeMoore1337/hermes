## Обоснованный узкий пробел

Clear Voice — прежде всего инструкция редактору, а не детерминированный
проверочный барьер. В Hermes можно без нового LLM и копирования skills
отмечать **кандидатные риски** в только публичном синтетическом черновике:

- процент с отсутствующей отметкой источника того же предложения;
- ссылка на неизвестный source ID;
- абсолютное медицинское обещание — обязательна экспертная проверка;
- формулировка о нарушении закона/штрафе — только REVIEW_REQUIRED,
  никогда не автоматическое юридическое заключение.

Код: editorial_review.public_draft, режим только PUBLIC_SYNTHETIC.
Никаких прав на публикацию, переписывание текста, изменение YFC или
вывод подтверждённого нарушения законодательства.
Он **не доказывает** ни истинность ссылки, ни медицинскую достоверность,
ни соответствие законам. Отсутствие срабатываний означает
NO_FLAGS_NOT_APPROVAL. Обнаруженные сигналы — не штраф и не обвинение.

Детерминированная регулярная проверка ограничена простыми контекстами:
Markdown code fences пропускаются; сложные цитаты, сноски, таблицы,
неявное указание источника и контекст могут давать false positives/negatives.
Результат не содержит исходный текст. В маленьком синтетическом негативном
корпусе из четырёх предложений проверены 0 ложных срабатываний;
**это не оценка точности на реальных публикациях**.

## Вызов без сети

Формат JSON для теста:
{"schema":"hermes-h13-public-draft-v1","visibility":"PUBLIC_SYNTHETIC","kind":"scientific_draft","text":"В части работ отмечено 25%.","source_ids":["S1"]}

Команда:
python3 -m editorial_review.public_draft --stdin < synthetic-draft.json

Отчёт — только коды и номера предложений. Скрипт не выполняет запросы,
не получает текущие нормативные акты, не отправляет текст в сеть, не
перезаписывает черновик и не принимает редакционного решения.

## Условия перехода к юридическому анализу

Без отдельной задачи YFC compliance, подтверждённой законной цели,
точных официальных ссылок на **актуальные версии** норм, оценки
лицензии, privacy и owner/legal approval — автоматический юридический
сканер оставлять **NOT_STARTED**. Здесь нет и не заявляется
проверенного набора нормативных актов. Не запускать legal-scanner
или OpenRouter, не отправлять пользовательские документы в Jina Reader.

Статус H-13: офлайн-прототип узкого QA-сигнала готов к review;
реальная редактура YFC, правовой анализ и публикации НЕ выполнялись.
