# H-13 / #65 — русскоязычный офлайн preflight без юридических вердиктов

Срез **16.10.2026**. Режим **OFFLINE_ONLY / MANUAL_REVIEW / NO_PUBLICATION**.

## Что уже есть и зачем узкое дополнение

- **Clear Voice 1.0.0** в проекте YFC: отдельный переносимый редакторский skill, профили YFC / Second Brain / Hermes, защита фактов, неопределённости, юридических условий и ссылки на источники. Он **не является машинным юридическим валидатором**, не запускается автономно в Hermes runtime и не гарантирует оценку текста моделью. Канонический путь в YFC: .agents/skills/clear-voice/README.md.
- **anti-ai-skill** (https://github.com/artemiimillier/anti-ai-skill): более узкие детерминированные стилевые подсказки, диагностика 26 осей, отдельные профили речи и расшифровок, калибровка p90, скрипт исправления типографики. Для Hermes берём *идею диагностировать и показывать проблемы, не переписывая текст*, а не чужой runtime/все стилистические правила. Нулевые совпадения не означают хороший текст. Исходные файлы стороннего репозитория не копировались.
- **legal-scanner** (https://github.com/artemiimillier/legal-scanner): сайт через Jina Reader, далее платный OpenRouter/Claude, юридическая база legal.md **по README является заглушкой**. Штрафы или нарушения из такого прототипа нельзя считать достоверным compliance verdict. Не устанавливаем, не вызываем OpenRouter, Jina Reader, не передаём туда YFC-контент.

Новый Hermes-owned модуль editorial_preflight.ru_check проверяет *только явно предоставленный локальный текст*. Предлагает ограниченные сигналы для редактора: упоминание нормативного акта, утверждения о штрафах/обязательностях, отдельные штампы и категорические обещания. Никакого автопереписывания, проверки грамматики, legal inference или публикации.

## Использование (только вручную)

При обычном вызове python -m editorial_preflight.ru_check возвращает NOT_EXECUTED, текст не читает. Для сознательного запуска:

    python -m editorial_preflight.ru_check --execute --file /absolute/path/to/draft.md --profile legal

На Windows передавать абсолютный путь к специально подготовленному обезличенному .md/.txt файлу. Размер <=64 KiB, UTF-8. Symlink/hardlink, бинарные файлы, неподдерживаемые расширения, невалидные управляющие символы — отказ. File descriptor подтверждается по inode/device после открытия. Ничего не сохраняет, не удаляет, не пишет в файл, не вызывает сеть или LLM, не запускает фоновый job.

Выводит только код срабатывания и символьное смещение, но **никогда сам фрагмент, файл, URL, токен или персональные данные**. Этого достаточно для локального поиска редактором; нельзя загружать персональные/секретные тексты в логи. Результат:

- REVIEW_HINTS — нашлись эвристические совпадения, это **не доказательство нарушения**;
- NO_FINDINGS_NOT_APPROVAL — совпадений нет; это **не проверка законности/качества**;
- LEGAL_* ⇒ MANUAL_LEGAL_SOURCE_CHECK; STYLE_* ⇒ OPTIONAL_EDITOR_REVIEW;
- legal_compliance_verified=false, current_legislation_verified=false, scientific_claims_verified=false, publication_allowed=false **всегда**;
- official_portal_link_seen_not_verified означает только присутствие точного HTTPS hostname pravo.gov.ru либо publication.pravo.gov.ru; никаких проверок действующей редакции нормы, применимости или срока действия не сделано.

## Корректная проверка первоисточников

Официальный ресурс для поиска опубликованных нормативных актов — https://pravo.gov.ru/ и раздел официального опубликования https://publication.pravo.gov.ru/. Это **начальная точка проверки**, не гарантия применимости закона к конкретному сервису/периоду. Даже при наличии ссылки требуются квалифицированная юридическая проверка, актуальная редакция и контекст использования. Автоматическая оценка штрафов сознательно **не реализована**.

## Фактические тесты и качество

Внутри tests/test_h13_ru_preflight.py: 7 явных позитивных и 6 негативных русских примеров (без личных данных); позитивные триггеры 7/7, негативные тексты 6/6 без ложных совпадений **только в этом маленьком синтетическом наборе**. Дополнительно есть негативные тесты на цитаты/код, URL-подмену, лимиты, bad UTF-8, симлинки, жёсткие статусы и отсутствие побочных действий.

Слепая оценка реального русского корпуса, настройка false positive, официальные юридические заключения и проверка конкретных норм = **NO_DATA / DEFERRED_TO_OWNER_REVIEW**. Точечные совпадения могут быть допустимы в юридических/научных текстах. Никакого массового исправления или удаления правовых предупреждений.

**Deploy:** только исходники и тесты в versioned release; не активировать в production pipeline или YFC. #65 остаётся PARTIAL до испытания на отдельно одобренном обезличенном корпусе и проверки действующих норм юристом.
