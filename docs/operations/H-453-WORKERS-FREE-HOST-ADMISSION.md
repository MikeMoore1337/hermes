# H-453 — Free-only A/B: подготовка на реальном хосте

Связано: [Hermes #453](https://github.com/MikeMoore1337/hermes/issues/453), Draft PR #527.
**Статус:** отдельный проектный эксперимент, **не production**, **не native delegate_task**. На реальном VPS ещё **NOT_RUN**.

## Наблюдаемые входные данные

Владелец подтвердил Workers Free, отсутствие AI Gateway, ограниченный A/B
и остаток 10 000 Neurons на 23.10.2026. Эти сведения со временем устаревают.
Инструменты Hermes BRC в ChatGPT показывают отдельные Linux/Docker песочницы,
**не настоящий VPS** и **не его защищённые файлы**. Никогда не переносить
токен/Account ID/исходный `.env` через чат, GitHub, сообщения или CI.

## Разовая подготовка на авторизованном VPS

Использовать **только отдельную непубликуемую копию** проверенного SHA PR #527;
не выполнять команды в каталоге работающего сервиса. Нужна учётная запись,
которая вправе читать `/var/lib/hermes-agent/.env` (режим строго `0600`);
никаких новых токенов/подписок/шлюзов. Не запускать под другой учёткой ради
обхода прав и не выводить содержимое `.env`.

После свежей проверки **того же аккаунта** в Cloudflare Dashboard оператор
записывает реально наблюдавшийся остаток и точное UTC-время наблюдения.
Не заменять время наблюдения текущим временем скрипта и не использовать
значение 10 000 из старой переписки как новую квоту.

Из каталога отдельной копии (ниже значения N и T вводятся локально):

```sh
python3 -B -m scripts.h453_account_preflight \
  --remaining-neurons N \
  --dashboard-checked-at "T" \
  --confirm-workers-free --confirm-no-ai-gateways \
  --output "$HOME/.local/state/hermes/h453/account-status-YYYYMMDDTHHMMSSZ.json"
```

Без `--write` это **read-only readiness check**: 0 запросов к AI,
0 новых файлов. При подтверждённом результате `PREFLIGHT_PASS` отдельный
запуск **с `--write`** создаёт один новый файл без перезаписи: приватный
каталог `0700`, файл `0600`. Сохраняется только SHA-256 отпечаток
Account ID, не токен и не сам ID; формат сверяется с
`agent_budget.pilot.load_account_status`. Статус остаётся
**OWNER_DASHBOARD_NOT_API_ATTESTED**, а не независимым биллинг-доказательством.

## Следующий отдельный этап — только после readiness и security review

`scripts.h453_bounded_ab` по умолчанию **не вызывает модель**.
Его live-режим требует свежий account-status JSON, одновременно
`--owner-approved` и `HERMES_AI_LIVE_APPROVED=1`, защищённые пути
состояния/результатов и тот же разрешённый Cloudflare-аккаунт.
Экземпляры клиента читают существующий локальный `.env` через строгий
`scripts.cloudflare_text_probe.read_env` (без shell `source`), только
когда оба env-параметра отсутствуют. Половинчатое окружение отклоняется.
Подключение только к прямому Workers AI API с фиксированной моделью
`@cf/openai/gpt-oss-20b`; без AI Gateway, Codex CLI, MCP, платного
fallback, ретраев, публикаций и новых служб. До возможного запроса
резервируются три дневные попытки (без возврата при неопределённом исходе).
Не запрашивать продление квоты или изменение тарифа.

**Ограничение:** стандартный ответ Cloudflare может не содержать
`usage.cost_usd`. Если стоимость отсутствует, A сохраняет `BLOCKED`
и два последующих B-запроса **не выполняются**; нельзя подставлять
вместо отсутствующей стоимости предполагаемые `0 USD`.
Даже три реальные модельные HTTP-запроса — это ещё **не** два нативных
субагента Hermes `delegate_task`. Требования прав/идентичности/отчётов
нативного делегирования остаются открытыми по #474/#475.

На BRC-песочницах настоящий токен и файлы хоста не обнаружены;
реальный запуск и его стоимость **NOT_RUN/NOT_MEASURED**.
