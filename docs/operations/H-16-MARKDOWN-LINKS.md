## Детерминированная проверка

```sh
python3 scripts/check_markdown_links.py
```

Нужен только Python стандартной библиотеки. Автоматически проверяются существование относительных файлов/каталогов, локальные якоря, попытки выхода за корень репозитория, абсолютные и небезопасные локальные пути, символические ссылки на внешние файлы. Текст в fenced/inline коде пропускается. Диагностика показывает только относительный путь, номер строки и заранее заданный код причины, не выводит URL с потенциальным токеном.

Результат первого запуска по `main` и новым проверкам: **68 Markdown-файлов, отсутствие ошибок локальных targets/anchors**. Отдельно после добавления кода пройдены **601/601 offline unit tests** в Linux-контейнере. В CI команда включена до тестов, без вызова HTTP, платного провайдера и дополнительных зависимостей.

## Ограничения

Markdown - сложный формат: регулярный шаблон покрывает стандартные inline links `[text](file.md#anchor)`, а не полную спецификацию CommonMark, HTML links и ссылочные определения `[text][ref]`. Проверка якорей приближает GitHub slug для типовых заголовков; сложные HTML и пользовательские ID требуют отдельного рассмотрения. **Не выдавать локальный PASS за доступность внешних страниц или корректность научных выводов.**

Статусы внешних HTTP (403, 404, 429, временные 5xx, redirect, timeout) требуют отдельной явной bounded read-only проверки только разрешённых публичных адресов. Она не должна блокировать обязательный CI при недоступности внешнего поставщика и не должна обращаться к private GitHub/YFC/Telegram/Second Brain.


## Отдельная необязательная проверка публичных HTTPS-адресов

Из корня репозитория:

~~~sh
python3 -m scripts.check_public_reference_links
# NOT_EXECUTED; никакой сети
python3 -m scripts.check_public_reference_links --execute
# 0: два HEALTHY; 2: REVIEW/UNKNOWN
~~~

Запросы разрешены **только к двум фиксированным публичным ссылкам**, уже упоминающимся в материалах Hermes: `api.crossref.org/works/10.1038%2Fs41586-020-2649-2` и `europepmc.org/RestfulWebService`. Это не произвольное сканирование всех внешних ссылок. Протокол: HEAD, HTTPS с TLS-верификацией имени, закреплённый публичный IP после DNS-проверки, максимум 2 запроса, 4 секунды на соединение, без редиректов, прокси, токенов, cookies и повторов. Ответы и внешние тексты не сохраняются, выводятся только предопределённые имена и состояния.

- `2xx` -> HEALTHY (доступность HEAD, **не** научная корректность содержимого).
- `404/410` -> BROKEN, общий REVIEW для ручной проверки.
- `301/302/303/307/308` -> REDIRECT_UNFOLLOWED, общий UNKNOWN, никакого следования потенциально приватной цели.
- `401/403/429/5xx`, DNS, TLS и timeout -> UNKNOWN, **не** ложный 404 и **не** падение обязательного CI.
- Ветка тестов имитирует положительные и отрицательные HTTP-кейсы, нет сетевых тестов в CI.

Фактический разовый запуск 15.10.2026 с отдельного компьютера: Crossref HEAD = `HEALTHY`, Europe PMC public docs = `UNKNOWN`, общий `UNKNOWN`, exit 2. Эта неопределённость **не доказывает, что ссылка сломана**. Временные ограничения ответов не пытались обходить. Не тестировались private GitHub, Telegram, YFC или Second Brain. Рабочий VPS и systemd не изменялись. Это ручной аудит двух выбранных публичных ссылок, не полная проверка доступности интернета.
