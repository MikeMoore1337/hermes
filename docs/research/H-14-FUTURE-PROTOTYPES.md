**Важная ловушка AI Smetchik:** [`lib/llm/calculate.ts`](https://github.com/artemiimillier/ai-smetchik-idey/blob/756a4e409f40ec5a094f737667d50663dbd6c517/lib/llm/calculate.ts) отправляет идею в `openrouter.ai`, получает модельные `team_cost_rub`, `solo_cost_rub`, времена, `confidence`; prompt содержит ориентиры денежного разрыва до 30–100x для ряда категорий. [Калибровочный вывод](https://github.com/artemiimillier/ai-smetchik-idey/blob/756a4e409f40ec5a094f737667d50663dbd6c517/plans/phase-1-calibration-output.md) - примеры генерации, **не внешняя валидация бюджета и сроков**. Внутренняя подсказка `confidence=medium` не есть измеренная вероятность. Если оценка вообще нужна: диапазон человеко-дней **только при раскрытых предположениях**, отдельно затраты на инструменты, время владельца, внешние расходы, верификация ставок и неизвестные. Не переносить ценовые множители и рекламные CTA.

**Проверенная SRS-механика ENGLESY:** [`web/js/engine.js`](https://github.com/artemiimillier/englesy/blob/ef41c042cf8edcde0d79314605a9932fbaa63a33/web/js/engine.js) использует `[0,1,3,7,16,35,90]` дней. `recordResult(pass)` сдвигает индекс на 1, `skip` сбрасывает на 0, due высчитывается из даты; `buildSession` предпочитает due/new и исключает повтор показанной сегодня фразы. Это понятный детерминированный baseline, но **не персонализированный scheduler**: нет оценки качества ответа, интервал не вычисляется по запоминанию; отложенная/пропущенная в этот же день карточка может не вернуться до следующего дня из-за `seenToday`. Проверять качество на собственной синтетике, не объявлять этот набор интервалов оптимальным.

## Реализация, цена, переносимость и приватность

- **Точечный GO для Toolkit #53 (без новой Issue):** добавить в текущий Product Discovery output contract опциональный блок `features -> exclusions -> uncertainty/risk -> smallest MVP -> validation`; при запросе оценки - диапазоны трудоёмкости с явными источниками ставок, допущениями, полнотой QA/безопасности/эксплуатации и раздельными cash/time. Критерий: на 3 синтетических идеях и пустой ввод выдаёт `UNKNOWN` вместо выдуманной стоимости, оставляет валидацию пользователю. Работы запланированы в #53, **никакого нового сервиса**.
- **Точечный GO на педагогические принципы (без новой Issue):** у YFC уже есть детерминированные подсказки по прогрессии, onboarding, AI Coach с review. Не добавлять контекстные учебные подсказки до проверки конкретного запутанного пользовательского сценария. Если появятся подтверждённые ошибки, открыть YFC Issue и использовать статические тексты, `why / how to fix / retry` с проверкой на доступность; не подключать AGPL.
- **Отдельный языковой MVP - DEFER, не запускать:** если запрос/валидация появятся, предложить PWA без backend/account/LLM: 20-40 **самостоятельно написанных** фраз, две фазы (воспроизвести/вспомнить), due-очередь, skip/retry, явно локальный прогресс с экспортом/очисткой, кнопки и optional browser TTS; browser ASR только opt-in с предупреждением, что распознавание может передавать голос провайдеру. Успех: пользователю понятен сценарий и он возвращается к due-упражнениям в течение согласованной проверки; отказ: упражнение не помогает или требует серверных функций без доказанной потребности. Числа фраз - граница предложения, **не утверждённые требования**.
- **Детерминированно без LLM:** очередность/due/SRS, метрики, локальное состояние, проверка формы, выбор упражнения, подсказка и порог прохождения. Простые алгоритмы воспроизводимы, бесплатны и офлайн; LLM допускается только для необязательного, отдельно разрешённого создания/проверки учебного контента и не заменяет педагогическую валидацию. Speech-to-text не измеряет акцент/фонемы без специализированной системы.
- **Техника:** Windows/Linux/Web/mobile текстовый PWA возможен с бесплатным browser runtime, без выделенного GPU и backend; но PWA install/offline проверяются на каждом целевом браузере, а не выводятся из JavaScript. Electron menu bar macOS и launchd не переносить на Windows. MediaPipe модель+WASM и возможный GPU существенно увеличивают загрузку, тепловой/CPU/RAM бюджет; измерений нет. Для нового PWA: disk/IndexedDB/localStorage, версии контента, удаление, тест восстановления, ограничения хранилища и обслуживание. При отсутствии сервера recurring стоимость трафика остаётся у хостинга сайта; локально открываемый offline bundle устраняет этот платёж, но требует дистрибуции и обновлений. Ни рублёвые бюджетные суммы, ни «навсегда бесплатный» хостинг не подтверждены.
- **Датчики и privacy:** разрешение microphone/camera запрашивать только при отдельном user gesture; отказ не блокирует текстовый путь. Не записывать аудио/видео и не хранить транскрипты по умолчанию; явная очистка локального прогресса, отключение датчиков, видимый индикатор режима. Web Speech recognition в ряде браузеров использует удалённый сервис, **не гарантирует offline** ([MDN SpeechRecognition](https://developer.mozilla.org/en-US/docs/Web/API/SpeechRecognition)); on-device `processLocally` экспериментален ([MDN](https://developer.mozilla.org/en-US/docs/Web/API/SpeechRecognition/processLocally)); `SpeechSynthesisVoice.localService` показывает локальный/удалённый голос ([MDN](https://developer.mozilla.org/en-US/docs/Web/API/SpeechSynthesisVoice)). Ни реальная запись, ни пользовательские данные не тестировались.
- **Лицензирование:** исходный код AI Smetchik и NEUROLING без найденного LICENSE - **не копировать**; отсутствие файла не позволяет делать вывод о любых отдельно предоставленных правах. ENGLESY/Slava/Starter - MIT на их код, но отдельно проверять mp3, учебные тексты, изображения, модели, шрифты, CDN и генерируемый контент. Gambitik AGPL-3.0-or-later; Stockfish GPL, контент/записи имеют отдельные условия. Перед любым импортом составить per-asset лицензии/NOTICE; сейчас **весь импорт REJECT**.
